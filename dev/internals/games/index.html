Internals: games and geometry

Logit games, normal-form payoffs, bordered solves and step metrics.

GameTracing.BranchWorkspace — Type
BranchWorkspace(game, point)

A residual, Jacobian, logits and game's pass work arrays (pass_workspace) for branch points like point = [w; λ], refilled by every call of the one callable that owns it. BifurcationKit consumes each result before calling that callable again, so the fused system and the Jacobian each own one workspace per trace; a shared one would let J overwrite a residual FJ returned.

GameTracing.GameResidual — Type
GameResidual(game)

BifurcationKit's F(x, pin) of game's branch in payoff gaps, with the precision carried as the state's last coordinate: x = [w; λ], F = [w - G(λ w, λ); λ - pin]. The logits are z = λ w, so F = 0 is z = λ G(z, λ), and F stays regular at λ = 0. pin is BifurcationKit's continuation parameter, which only pins λ. Each call fills a fresh BranchWorkspace: BifurcationKit keeps its problem's F apart from the fused system.

source

GameTracing.PinSlope — Type
PinSlope(start)

∂F/∂pin of the branch residual [F(w, λ); λ - pin], BifurcationKit's jet R01: [0 … 0 -1], exactly, in start's element type and length. BifurcationKit copies the vector it gets, so one serves every call. The constructor is inner because the field's default one would take start itself as the slope.

GameTracing.contract_axes! — Method
contract_axes!(target, source, dims, group, weights)

Contract the adjacent axes group of the tensor source of size dims, read in linear order, into target: the slices along the group, each times its joint weight in weights (group_weights!), summed. Return the new size, one along group. A block past the group holds one stride-long run per slice. The inner loop runs along a run when it is at least as long as the slices are many, else across the blocks; each entry adds its slices in order either way.

GameTracing.write_gain_slope! — Method
write_gain_slope!(block, payoff, work, player, rival)

∂G_pk / ∂z_qj of player p in the logits of rival q, into block, from the sensitivities D_ki = ∂U_p(k) / ∂π_qi and expected payoffs in work (contract_payoff!). GameTracing.write_marginals! — Method
write_marginals!(work, tensor, dims, positions, player, depth, every_rival)

For each rival q at positions (rival_axis), the tensor tensor of size dims with every axis but player's and q's contracted, into work.sensitivities[q]. The other rivals' axes are already contracted. Contract each half of the rivals in turn and recurse into the other half, in work.tensors[depth], down to two rivals (write_pair_marginals!): a few passes over tensor in all. Without every_rival, write only the first rival's marginal, by the first branch alone: it rounds as with every_rival.

GameTracing.InPlaceMatrixBLS — Type
InPlaceMatrixBLS(factorization, rhs, solver)

BifurcationKit's MatrixBLS with the bordered matrix written into factorization's factors and LU-factored there (lu!), and the right-hand side solved in place in rhs; its solutions are bit-identical. Any real element type factors: LAPACK's for the BLAS floats, the generic LU otherwise. A triangular bordered matrix goes to \. solver is never read; it keeps PALC's update from replacing this solver with one built from the Newton options. The system is [J dR; ξu dzu' ξp dzp] [dX; dl] = [R; n], J the trace's width × width Jacobian.

The returned dX is a view of rhs, valid until the next solve. PALC's Newton step and tangent use it before then.

source
BifurcationKit.bordered_tangent_and_sign — Method

The Bordered tangent of PALC and the sign of the bordered matrix's determinant that its orientation_check reads, from one LU: the matrix is built as MatrixBLS builds it, from PALC's θ and dotθ, factored in bls's buffers (lu!), the tangent solves with that factorization, and the sign is its determinant's (logabsdet). A zero pivot makes the matrix singular: the sign and the tangent are zero, which PALC's NaN checks refuse as a step.

source

GameTracing.FisherLogPrecisionWeights — Type

weights! of a FisherLogPrecisionDistance trace's PointWeightedDot, under PALC state weight palc_state_weight (log_precision_palc_state_weight), both weights at the accepted point:

  • each gap: its Fisher weight σ(z)σ(-z) times gap_scale = state_weight / palc_state_weight;
  • the precision: (log_precision_scale - (1 - palc_state_weight)) / palc_state_weight.

PALC's palc_state_weight ⟨Δx, Δx⟩ + (1 - palc_state_weight) Δλ² is then the distance's norm.

source

GameTracing.palc_geometry — Method

(; palc_state_weight, dot): PALC's θ and dotθ for geometry over a trace of width gaps to precision target_precision. PALC's norm of [Δx; Δλ], x = [w; λ], is palc_state_weight ⟨Δx, Δx⟩ + (1 - palc_state_weight) Δλ². A plain-norm distance (plain_weights: gap, precision) runs PALC at plain_palc_state_weight(precision), and the inner product weighs each gap by gap / palc_state_weight (times its Fisher weight under FisherDistance) and the precision by (precision - (1 - palc_state_weight)) / palc_state_weight.

A FisherLogPrecisionDistance trace runs PALC at log_precision_palc_state_weight instead (FisherLogPrecisionWeights). Every state_weight in (0, 1) is valid, at every width; another throws an ArgumentError.

source
